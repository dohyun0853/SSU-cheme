Notes

이렇게 동작합니다

  1. 01
    브라우저에 먼저 저장

    공지·교수진을 고치면 이 브라우저의 홈페이지에 즉시 반영되고, 새로고침해도 유지됩니다. 방문자에게는 아직 보이지 않습니다.

  2. 02
    data.js 내려받기

    수정 내용 전체가 담긴 파일을 받아 둡니다. 백업이자, GitHub 없이도 배포할 수 있는 수단입니다.

  3. 03
    GitHub 커밋

    저장소의 data.js를 같은 내용으로 바꿔 커밋합니다. 커밋이 끝나면 모든 방문자가 보는 홈페이지가 갱신됩니다.

토큰 발급 (1회만)

GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Only select repositories에서 SSU-cheme 선택 → Repository permissions의 Contents를 Read and write로 지정 → 생성 후 한 번만 복사.

Scope

이 관리자 모드의 범위

  • 할 수 있는 일

    이 브라우저에서 보이는 공지·교수진을 고치고, data.js로 내려받고, GitHub 저장소에 커밋하는 일.

  • 할 수 없는 일

    서버가 없는 정적 사이트라, 로그인은 화면을 여는 잠금장치입니다. 방문자의 화면을 직접 바꾸지 못하며, 실제 반영은 GitHub 커밋으로만 이뤄집니다.

  • 그래서 비밀번호는

    기본값을 그대로 두면 누구나 이 화면을 열어 볼 수 있습니다. 처음 로그인한 뒤 위에서 바로 바꿔 주세요.
